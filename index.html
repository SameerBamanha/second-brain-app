Your memory stays in your private repo. This page reads and writes it straight from your browser with a token only you hold.

      
      
      
      

      
      

        How to make a token
        
    
          
  1. Open GitHub → Fine-grained tokens → Generate new token.
    2. 
          
  2. Repository access: Only select repositories, then pick your second-brain repo.
    3. 
          
  3. Permissions → Repository → Contents: Read and write (Read-only works if you only want to view). Nothing else.
    4. 
          
  4. Choose an expiry, generate it, and paste it here.
    5. 
        

        
The token is kept only in this browser and is sent only to api.github.com.
